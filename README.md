# Dark Veil downloads

Official native downloads for [Dark Veil](https://playdarkveil.com), a dark fantasy FPS roguelite.

[Download Dark Veil 0.50.0 for Mac](https://github.com/Dimillian/DarkVeil-downloads/releases/download/v0.50.0/DarkVeil-0.50.0-macOS-arm64.zip)

Requires an Apple Silicon Mac running macOS 13 or later. The app is signed with
Developer ID, notarized by Apple, and includes its notarization ticket.

Unzip the download, move **Dark Veil.app** to Applications, and open it.

[All downloads](https://github.com/Dimillian/DarkVeil-downloads/releases) ·
[Release history](https://playdarkveil.com/changelog/) ·
[Play in browser](https://playdarkveil.com/game/)

Each release includes a SHA256SUMS.txt checksum file. From the download folder,
run `shasum -a 256 -c SHA256SUMS.txt` to verify the ZIP.

This repository contains public downloads and release notes. Game source is maintained separately.
